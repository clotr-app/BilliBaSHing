# BilliBaSHing

I made `test-text/` as a repeatable set of fictional messages for comparing privacy and secret detectors. It includes expected finding kinds and character spans, plus negative examples that should not be flagged. Every example is synthetic and includes an expected kind and span or an empty expected set.

Start with [`test-text/README.md`](test-text/README.md) for the data format and scoring. Cite it with [`CITATION.cff`](CITATION.cff). The dataset is CC BY 4.0. The scorer and generator are MIT licensed.
